# 安全与权限模型

## 信任边界

- UI 只能通过 Tauri 命令访问系统；模型永远不直接接触文件系统、Shell 或凭据。
- 每个项目在添加时规范化真实路径，后续所有文件工具都以该 canonical root 为边界。
- API Key 由 Rust 端从 Windows 凭据管理器读取，仅注入 HTTP 请求头；不返回前端。
- 普通聊天没有文件 / 命令工具；副作用只发生在用户明确创建的 Agent 任务中。

## 文件系统

- 只接受项目内相对路径；绝对路径、`..`、前缀组件与 NUL 拒绝。
- 对已存在路径使用 `canonicalize` 后比较；对新建路径规范化最近存在祖先，
  阻止符号链接逃逸。
- 禁止写入 `.git/`、`.basalt/` 与应用数据库文件。
- 读取上限 2–5MB（工具/预览），写入上限 2MB；二进制文件拒绝文本写入。
- 用户手动保存文件时校验当前 hash，外部修改会阻止覆盖。
- Agent 每次写入前保存旧内容快照；接受/撤销前再次校验当前 hash。
  冲突时标记 `conflict`，必须明确选择强制恢复。

## 终端命令

Agent 命令：

- 以 PowerShell 非交互模式执行，cwd 受限于项目内相对目录。
- 默认需要用户批准；可在设置中关闭审批（用户明确承担风险）。
- 固定超时（默认 120s，可设 5–600s）；可取消；超时/取消执行进程树终止。
- 不使用字符串拼接构造 Shell；模型提供的命令作为单个 `-Command` 参数。
- 用户终端使用 ConPTY，与 Agent 命令分开记录来源；终端标签保留退出码。

硬拒绝（不可通过审批绕过）：

- 磁盘格式化/分区、关机/重启、启动配置修改。
- 注册表修改、账户/服务/计划任务/防火墙/执行策略修改。
- 编码命令、`Invoke-Expression`、下载后直接执行管道。
- 请求管理员提权、启动脱离任务生命周期的后台进程。
- 递归删除根目录/通配符目标、`git clean -fdx`、`git reset --hard`。
- 访问 UNC 网络路径、项目外绝对路径，以及用户 / 系统目录环境变量。
- `takeown` / `icacls` 提权改权限、卷影/备份操作。

需要批准但允许：

- 常规构建、测试、包管理器安装、`git status/diff`、读取项目文件等。
- `git push` 与发布命令会作为外部副作用要求明确批准。

## 密钥与日志

- API Key 存于 Windows Credential Manager，service `com.basalt.workbench`，
  账户为 provider id；数据库只保存元数据与 `hasKey`。
- 前端密钥输入只提交一次；保存后清空输入与内存状态。
- 自定义请求头禁止覆盖 `Authorization` / `x-api-key` 等敏感头；
  核心认证由适配器控制。
- Base URL 拒绝内嵌用户名/密码；Gemini 使用 header 而非 URL query。
- 日志会过滤 `sk-` / `xai-` / `aiza` 前缀令牌；不记录请求头或附件内容。
- 工具参数与命令会保存在本地 `tool_calls` 表用于审计；请不要把密钥写进命令/提示词。

## 附件与图像

- 附件仅支持常见图片与文本/代码扩展名；拒绝 `.env*`、私钥、`.pem/.key/.pfx` 等。
- 图片校验 magic bytes 与 10MB 上限；文本 1MB 且必须 UTF-8；单条消息最多 8 个。
- 附件复制到工作台数据目录；远端模型只收到用户选择的附件，不上传整个项目。
- 生成图片仅能保存工作台 images 目录中的文件到用户选择的位置。
- 远程生成图片 URL：HTTPS、拒绝私网/loopback/本地域名、DNS 解析安全检查、
  禁止重定向、30MB 上限。
- 图像生成失败会返回真实错误，不使用占位图伪装成功。

## 数据边界

- SQLite、附件、图片、快照与日志位于 Tauri app data 目录。
- 删除会话/任务时删除对应消息与记录；快照文件与附件目前保留（磁盘占用需手动清理），
  删除生成历史会删除对应图片文件。
- 取消/退出时终止终端进程与在途请求；下次启动标记中断任务，不重放历史工具调用。

## 已知限制

- 命令审批是安全控制，不是 OS 沙箱；被批准的命令拥有当前用户权限。
- 路径/命令静态策略无法覆盖所有 PowerShell 语法变体；因此默认审批不可关闭为“始终允许任意命令”。
- 模型输出可能包含提示注入；应用只执行通过工具 schema、策略与审批的操作。
- WSL 命令只用于用户手动终端；Agent 不会绕过策略改用 WSL。
- 异步图像任务当前未启用；未来启用时必须提供真实状态查询与取消。

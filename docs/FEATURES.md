## 已实现

### 工作台与界面

- 独立品牌 BASALT、统一设计 Token、深浅色主题与跟随系统、5 套整页配色与平滑过渡。
- 左侧图标 Rail + 项目 / 会话 / 任务 / 文件树侧栏，可折叠、可调整宽度。
- 中央聊天 + Agent 时间线 + 右侧代码 / 变更 / Diff + 底部终端，面板可调整/折叠。
- 全局搜索过滤（会话、任务、已加载文件）。
- 布局尺寸与折叠状态持久化（localStorage）。
- 常用快捷键。

### 对话

- 多轮、流式输出、停止、重试、模型/供应商切换。
- Markdown、GFM 表格、语法高亮、代码复制、链接复制。
- 图片与文本附件；拖拽导入；类型/大小/敏感文件名校验。
- 上下文 token 估算与模型上下文窗口显示。
- 独立 Image Provider 的 `/img` 对话内生图。

### Agent

- 任务创建、队列（全局串行）、开始、取消、删除、继续（中断/失败/取消）。
- 真实工具：计划、列目录、搜索、读文件、写文件、精确补丁、Git 状态/Diff、
  PowerShell 命令、测试执行、Bing/DuckDuckGo 联网搜索、公网网页读取、只读子代理。
- 思考强度选择器：off / minimal / low / medium / high / xhigh / max / ultra，
  按会话保存并映射到各协议。
- 每次写入/命令默认审批；审批等待、拒绝、超时；策略硬拒绝危险操作。
- 真实工具事件时间线：计划、工具调用、终端输出、测试结果、文件变更、报告。
- 工具调用按批次聚合为可折叠卡片：折叠显示按工具统计与总耗时，展开为紧凑步骤。
- 变更快照、单文件接受/撤销、hash 冲突检测与强制处理。
- 任务报告附带真实变更记录与最近测试退出码。
- Agent 默认 200 轮安全上限，达到后转为可继续的中断状态；旧版 20 轮上限自动迁移。
- Agent 任务失败/取消不会伪报成功。

### 终端

- PowerShell / CMD / WSL，多标签。
- 实时输出、退出码、尺寸自适应、搜索、复制、清屏、终止进程。
- 用户终端与 Agent 命令来源区分。

### 供应商与图像

- 供应商 CRUD、复制、启用/禁用、删除、模板。
- 模板：OpenAI Chat / Responses、Anthropic、Gemini、DeepSeek、MiniMax、Kimi、Qwen、
  GLM、Grok、OpenAI 兼容、自建网关、Ollama、OpenAI Images、Gemini Images。
- API Key 存 Windows 凭据管理器；Base URL、超时、流式、自定义头/参数。
- 模型卡片编辑器：上下文窗口预设、10 项能力 × 5 种状态的分组能力矩阵、批量标记与默认模型切换。
- 连接测试 / 拉取模型；最近连接状态与错误展示。
- 图像工作区：生成、编辑、参考图、蒙版（模型支持时）、尺寸/质量/数量/背景约束、
  历史、预览、保存、重生成、继续编辑、复制提示词、删除。
- 思考强度选择器：8 档，按会话保存并映射到各协议。

### 安全与架构

- 项目 canonical root 边界、符号链接校验、`.git` 保护。
- 危险命令硬拒绝、审批、超时、取消、进程树终止。
- API Key 不入库、日志脱敏、附件白名单、远程图片 SSRF 防护。
- 供应商适配器 / Agent Runtime / Image Provider / 事件总线解耦。
- SQLite 持久化与启动中断恢复。
- Windows EXE、NSIS 安装包、便携 ZIP 与 SHA256 校验和。

## 部分实现 / 已知限制

| 功能 | 现状 |
| --- | --- |
| Agent 规划模型独立路由 | 配置已持久化；当前 Runtime 使用统一的 Agent 执行模型完成规划与执行 |
| 视觉模型独立路由 | 配置已持久化；会话使用用户选定的模型；需要选择视觉能力模型 |
| 图像异步任务 | 当前适配器均为同步；能力矩阵显式标记“同步”，未提供轮询/取消 UI |
| 终端测试错误跳转文件 | 未实现点击路径跳转；测试结果与输出可查看、复制 |
| 终端标签跨重启 | 标签不持久化；应用退出会终止进程，重启从空终端开始（终端进程本身不会在重启后恢复） |
| 自动重试 / 故障切换 | 未实现自动策略；支持手动重试；不会静默切换到更高费用供应商 |
| 多参考图 / 多蒙版 | 当前一次一张参考图；不同供应商能力差异已披露 |
| 会话/任务删除时的快照清理 | 快照与导入附件保留在数据目录，需手动清理 |
| 供应商删除的级联 | 记录保留，路由引用清空；需重新配置 |

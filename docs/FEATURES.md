## 已实现

### 工作台与界面

- 独立品牌 BASALT、统一设计 Token、深浅色主题与跟随系统、5 套整页配色与平滑过渡。
- 四语言界面：简体中文 / English / 日本語 / 한국어，设置页即时切换；
  覆盖工作台、设置、供应商、图像与任务界面，模型输出、代码和终端内容保持原文。
- 日期、时间与相对时间按当前界面语言格式化。
- 下拉选择统一为应用内菜单，支持键盘方向键、Enter/Esc、自动上下翻转与选中标记，
  替换原生 `<select>` 弹层。
- 左侧图标 Rail + 项目 / 会话 / 任务 / 文件树侧栏，可折叠、可调整宽度。
- Rail 底部提供 GitHub 仓库入口：悬浮显示提示，点击用系统浏览器打开。
- 聊天 Markdown 链接点击后直接用系统浏览器打开（仅 http/https），不再复制到剪贴板。
- 输入框底部状态栏显示当前项目与 Git 分支；点击项目名可切换工作区或添加目录，
  点击分支可切换本地分支或输入名称新建分支。
- Git 工作流：变更面板可提交全部工作区变更、把单个已跟踪文件还原到 HEAD，
  并显示未解决的合并冲突；Agent 任务可按设置自动创建 `basalt/任务ID` 隔离分支。
- 输入框底部上下文占用条显示已用 / 上限与百分比；点击展开系统提示、消息、工具、
  输入与剩余容量明细。
- 状态栏缓存条按**当前会话** + 供应商 + 模型累计 tokens 与缓存命中率；切换会话后
  显示该会话自己的数据，新会话从零开始。点击展开 Token 用量面板：
  缓存命中率、未缓存输入、缓存读取与输出，标题显示含输出的总量。OpenAI Chat /
  Responses、Anthropic、Gemini 的缓存字段统一归一化，流式请求自动补 `include_usage`。
- 状态栏余额 chip 使用当前供应商的 API Key 查询账户余额；点击展开总余额、赠送余额、
  充值余额、可用状态与刷新按钮。支持 DeepSeek 官方与 Moonshot 官方接口；
  没有公开余额接口的兼容网关自动隐藏。Key 仅在后端读取，不进入前端或普通日志。
- 中央聊天 + Agent 内联工具 + 右侧代码 / 变更 / Diff + 底部终端，面板可调整/折叠。
- 聊天视觉：用户消息右对齐气泡；Assistant 消息使用轻量头像、品牌与模型标签，
  时间/复制在悬停时出现；连续回复只保留首个角色头。
- 输入框合并为单一圆角面板：文本区、操作栏与会话状态行在同一容器内，
  不再嵌套第二层边框。
- 终端占满可用宽度，默认高度更小并限制在窗口 32% 内；拖拽/xterm 自动适配，
  首次打开才挂载。
- 全局搜索过滤（会话、任务、已加载文件）。
- 布局尺寸与折叠状态持久化（localStorage）。
- 常用快捷键。

### 对话

- 多轮、流式输出、停止、重试、模型/供应商切换。
- 连续 Assistant 消息合并为一段：仅首条显示 BASALT 角色、模型与时间头，
  后续回复直接衔接，工具轮次之间不再重复起头。
- Markdown、GFM 表格、语法高亮、代码复制、链接复制。
- 图片与文本附件；拖拽导入；类型/大小/敏感文件名校验。
- 上下文 token 估算与模型上下文窗口显示。
- 独立 Image Provider 的 `/img` 对话内生图。

### Agent

- 任务创建、按项目并行队列、开始、取消、删除、继续（中断/失败/取消）。
- 真实工具：计划、列目录、搜索、读文件、写文件、精确补丁、Git 状态/Diff、
  PowerShell 命令、测试执行、Bing/DuckDuckGo 联网搜索、公网网页读取、
  单个/并行只读子代理、Skill 读取与已启用 MCP 工具。
- 思考强度选择器：off / minimal / low / medium / high / xhigh / max / ultra，
  按会话保存并映射到各协议。
- 每次写入/命令默认审批；审批等待、拒绝、超时；策略硬拒绝危险操作。
- 工具调用按轮次内联到对话中：默认折叠为摘要行，显示执行次数、失败数与取消数，
  展开为紧凑步骤；不再占一张独立任务卡片。
- 测试结果内联显示 PASS / FAIL、命令与退出码。
- 回复结束后在输入框上方显示运行统计：模型、模型耗时与输出 tok/s；
  运行中改为 Agent 状态与停止按钮，中断/失败/取消提供继续。
- 计划（TODO）与任务代码变更移到右侧面板：TODO 固定占面板 15% 高度，
  只显示前三项，超出可「显示更多」；代码变更列在 TODO 下方。
- 子代理任务树：右侧显示每个子代理的角色、状态、轮次与工具次数，可打开完整报告。
- 变更快照、单文件接受/撤销、hash 冲突检测与强制处理。
- 任务报告附带真实变更记录与最近测试退出码。
- Agent 与子代理均不设固定轮次 / 工具调用次数上限，可随时停止；任务失败或取消不会伪报成功。
- 费用控制：仅最近一条用户消息的图片/附件内容会再次发送；旧消息只保留文件名提示。
- Agent 工具回传模型的 JSON 总量上限 48k 字符，超出部分标记截断；界面预览不受影响。
- Anthropic Agent / 子代理/多轮聊天使用显式提示缓存（system、tools、最后消息），
  仅缓存会复用的前缀；兼容网关若拒绝 `cache_control` 会自动无缓存重试。
- 接口自动探测每次 `max_tokens=1`，每个模型只探测一次，结果持久化。
- 自动重试采用指数退避，且只在模型尚未输出文本时重试；可配置降级供应商，
  降级只发生一次，任务时间线显示重试与降级事件。
- 自动独立审查（默认关闭）：任务有变更时调用代码审查路由，结果写入会话并记录用量。
- Monaco、xterm、设置、供应商与图像视图按需加载；终端首次打开才挂载，
  避免首屏加载编辑器与终端运行时。

### 扩展与工具注册

- Skills：导入包含 `SKILL.md` 与可选脚本/模板的文件夹；支持启用、停用、删除和打开目录。
  Agent 系统提示只列出名称与描述，匹配任务后通过 `read_skill` 按需加载完整内容。
- MCP：支持 stdio 与 Streamable HTTP；保存配置后刷新工具，持久化会话、分页发现、
  工具 schema、只读标注、连接状态与错误。
- MCP 权限：默认每次工具调用请求批准；服务器可单独开启自动授权。禁用或删除服务器会结束本地进程。
- MCP 工具测试：管理页可直接执行 `tools/call`，显示结构化返回，不经过 Agent 审批。
- 插件包：`plugin.json` 可同时声明多个 Skill 与 MCP 服务器；安装时复制到应用数据目录、
  自动刷新服务器，卸载时清理其安装的 Skill、MCP 配置与本地副本。
- 统一工具注册表：内置工具、Skill 加载器与所有已启用 MCP 工具集中显示来源、只读性与审批要求。

## 部分实现 / 已知限制

| 功能 | 现状 |
| --- | --- |
| 视觉模型独立路由 | 配置已持久化；会话使用用户选定的模型；需要选择视觉能力模型 |
| 图像异步任务 | 当前适配器均为同步；能力矩阵显式标记“同步”，未提供轮询/取消 UI |
| 终端测试错误跳转文件 | 未实现点击路径跳转；测试结果与输出可查看、复制 |
| 终端标签跨重启 | 标签不持久化；应用退出会终止进程，重启从空终端开始（终端进程本身不会在重启后恢复） |
| 多参考图 / 多蒙版 | 当前一次一张参考图；不同供应商能力差异已披露 |
| 会话/任务删除时的快照清理 | 快照与导入附件保留在数据目录，需手动清理 |
| 供应商删除的级联 | 记录保留，路由引用清空；需重新配置 |
| MCP 高级协议能力 | 已实现 initialize、tools/list、tools/call；roots、sampling、elicitation 与资源订阅尚未接入 |

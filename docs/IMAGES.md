# 图像生成与编辑

## 独立架构

图像服务不依赖聊天模型：

- `ImageAdapter` 接口：能力声明、模型列表、生成、编辑。
- 设置中有独立的「图像生成」与「图像编辑」路由。
- 对话中的 `/img` 使用图像路由；当前聊天模型不需要具备生图能力。
- 图像服务失败时返回真实错误，不会用占位图伪装成成功结果。

## 支持的服务

| 协议 | 生成 | 编辑 | 参考图 | 蒙版 | 多图 | 异步 |
| --- | --- | --- | --- | --- | --- | --- |
| OpenAI Images | 是 | 是 | 是 | 是（模型支持时） | 是（受模型上限） | 否 |
| Gemini Images | 是 | 是 | 单张 | 否 | 否 | 否 |

实际参数以 `ImageCapabilities` 为准：

- 尺寸、质量、数量；
- 是否支持参考图 / 蒙版 / 透明背景；
- 单次最大数量；
- 同步/异步接口；
- 能力说明与限制。

UI 只展示当前模型支持的参数，服务端再校验一次；非法参数会明确报错。

## 提示词与结果

- 文本生图：提示词 + 模型支持的尺寸/质量/数量/背景。
- 编辑：提示词 + 参考图（+ 蒙版，若支持）。
- 结果显示在图像工作区历史中，可预览、保存到本地、重新生成、继续编辑、复制提示词、删除。
- 对话内生图会保留用户 `/img` 消息与图像消息；图像消息可直接保存或跳转图像工作区。

## 存储

- 生成图片保存在应用数据目录的 `images/YYYY-MM/`。
- 只允许把 `images/` 中的文件另存到用户选择的位置。
- 远程 URL 仅 HTTPS，拒绝 loopback/私网/内网解析，禁用重定向，限制 30MB。
- 删除生成历史会删除对应本地文件。

## 已知限制

- 当前所有图像适配器都是同步接口，因此没有异步任务轮询与取消。
- 参考图一次一张；不同供应商的限制在能力说明中展示。
- Gemini 不支持蒙版；OpenAI 蒙版支持取决于具体模型。
- 真实图像服务需配置 API Key 后验证；本机未执行真实生成。

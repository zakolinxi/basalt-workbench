# BASALT 设计系统

## 设计目标

BASALT 是工程工具，不是营销页面。视觉语言服务于信息密度、可读性和操作确定性：

- 黑白灰为主体，状态色仅表达语义。
- 直线、细边框、小圆角（2–4px），不使用装饰性渐变、玻璃拟态或霓虹。
- 高密度但不拥挤：统一的 4px 间距节奏、清晰的层级与分组线。
- 代码、Diff、终端优先保证等宽与可选择性。
- 动效仅用于反馈任务状态、面板切换与内容出现，时长 100–180ms。

## 品牌

- 名称：BASALT（玄武岩），强调稳定、本地、可依赖。
- 图形：三根高低不同的竖直柱体，寓意层叠的工程结构。
- 字体：UI 使用捆绑的 Inter Variable（拉丁）配合 Noto Sans SC / 微软雅黑（中文）；
  等宽使用捆绑的 JetBrains Mono。字体随应用打包，不请求远程字体，保证离线一致性。

| `--fg-0` | `#f0f0f2` | 主文本 |
| `--fg-1` | `#c3c3c9` | 正文 |
| `--fg-2` | `#8b8b93` | 次要信息 |
| `--fg-3` | `#5e5e66` | 辅助 / 元数据 |

浅色主题使用相同语义 Token，并保持足够的边框与对比度。终端的深色底色为有意保留，

语义色比例控制：界面 95% 由中性色构成，状态色只用于状态点、Badge、Diff 行和错误。

## 排版与密度

- 基准字号 13px，正文 14px（可由设置调整），元数据 9–10.5px。
- 等宽用于：路径、模型 ID、协议、状态、时间、工具参数与输出。
- 字距：小型大写标签使用 0.08–0.16em letter-spacing。
- 行高：UI 1.5；聊天正文 1.7；代码 1.55–1.6。
- 控件高度：主要按钮 30px，小按钮 25/21px；列表行 24–30px。
- 圆角：按钮与输入 3px，卡片 3–4px。

## 布局

```
[Icon Rail 52px] [Sidebar 264px] [Topbar]
                                   [Chat / Messages] [Right Panel 520px]
                                   [Composer]
                                   [Terminal 230px]
```

- 侧栏、右侧面板与终端均可拖动调整尺寸；折叠状态与尺寸保存在本地。
- 侧栏顶部是常驻工作区列表（项目、最近任务摘要），下方只保留会话搜索与会话列表；任务与项目文件不再占用侧栏。
- 右侧面板：代码 / 变更 / Diff，三个标签保持固定语义。
- 终端跨聊天与右侧面板，可整体收起；折叠时不销毁进程。
- 左侧图标栏（Rail）是全局一级导航：工作台、供应商、图像工作区、设置。

## 组件原则

- 所有页面共享同一套 Button / Input / Select / Badge / Modal / Toast。
- 按钮层级：主操作（反色实底）> 次要操作（描边）> 幽灵操作（无边框）> 危险（红色描边）。
- 不使用大面积阴影；只有模态框与菜单使用阴影表达浮层。
- 状态表达使用文本 + 颜色，不只依赖颜色。
- 所有可交互元素具备 hover / focus-visible / disabled 状态。
- 图标统一使用 Lucide 线性图标，默认 1.5–1.6px 描边，尺寸 10–17px。

## 交互

- Enter 发送，Shift+Enter 换行；IME 组合期间不发送。
- Ctrl+N 新会话；Ctrl+Shift+N 聚焦 Agent 任务；Ctrl+B 侧栏；Ctrl+` 终端；Ctrl+S 保存。
- Agent 任务的所有写入与命令默认暂停等待审批；审批栏固定于输入框上方。
- 任务时间线区分：模型文字、工具调用、真实工具结果、测试结果、文件变更、最终报告。
  工具调用按批次聚合为一张可折叠汇总卡，默认折叠；展开后为紧凑步骤。
- Diff 支持统一 / 并排视图，新增与删除行使用低饱和背景；冲突时弹出审查与强制恢复流程。
- 文件预览默认只读，进入编辑模式后才允许保存；外部修改通过 hash 校验阻止覆盖。

## 主题与可访问性

- 深色 / 浅色 / 跟随系统；通过 `data-theme` 切换同一套 CSS 变量。
- 5 套配色（玄武 / 森林 / 薄荷 / 蜜蜂 / 羊皮纸）只覆盖强调色 Token，背景保持中性；
  主题或配色切换使用 460ms 颜色过渡。
- 焦点可见性由 `:focus-visible` 统一提供。
- 支持 `prefers-reduced-motion`，关闭大部分过渡与动画。
- 最小窗口 1080×680；关键操作在窄窗口下仍可访问。

BASALT 0.3.0 — Windows x64
==========================

Basalt 是一个本地优先的 AI 编程工作台（Tauri 2 + React + Rust）。
从 0.3.0 起，手机可以远程接管电脑上的这台工作台。

本次更新
--------
- 新增手机客户端：同一 WiFi 下扫码或输入 6 位配对码即可连接。
  电脑端「设置 → 手机连接」打开开关后显示地址、配对码与二维码。
- 手机端与桌面端共用同一份界面与同一套后端命令：会话、Agent 任务、审批、
  变更 Diff、终端、供应商、Skills / MCP、图像工作区与设置全部可用。
- 手机与桌面窗口共享同一条事件流：流式回复、工具调用、审批请求与终端输出实时同步。
- 提供 Android APK 与 PWA 两种形态；浏览器打开地址后可「添加到主屏幕」。
- 手机看不到电脑磁盘，因此「添加项目」走电脑端目录浏览器；
  附件改为手机选取后上传，保存图片改为下载到手机。
- 窄屏自适应：手机上台式布局自动改为抽屉式侧栏、底部导航与全屏终端。
- 远程访问默认关闭，只监听局域网；配对码 10 分钟失效，连续猜错 6 次锁定 60 秒。

运行要求
--------
- Windows 10/11 x64
- Microsoft Edge WebView2 Runtime（Windows 10/11 通常已预装）
- 可选：Git（用于分支、提交、还原、Git 状态与 HEAD Diff）
- 可选：Windows PowerShell（Agent 命令与默认终端）
- 可选：Node.js / uvx（运行外部 MCP stdio 服务器）
- 手机端：Android 或任意现代浏览器；手机与电脑需在同一局域网

两种方式
--------
1. 安装版：运行 Basalt_0.3.0_x64-setup.exe，按向导安装。
2. 便携版：直接运行 Basalt.exe。便携版仍使用 %APPDATA%\com.basalt.workbench
   保存数据库、附件、Skills、MCP 配置与设置。

首次使用
--------
- 打开「供应商」，从模板创建供应商并填写 API Key。
- 在「设置 → 模型路由」分别配置 Agent 执行、规划与代码审查模型。
- 在「扩展」导入 Skill 文件夹，或添加 MCP 服务器后刷新工具。
- 添加本地项目目录后，输入框默认处于 Agent 模式。
- Agent 内置联网搜索、公网网页读取、并行子代理、Skill 与 MCP 工具。
- 输入框「思考」可选择 off / minimal / low / medium / high / xhigh / max / ultra。
- 使用 /img 提示词调用独立图像供应商。
- 全局请求 User-Agent 可在「设置 → 安全与数据」中修改。
- 手机接管：设置 → 手机连接 → 打开开关 → 手机扫码；
  或先安装 Basalt-Remote-0.3.0.apk，再手动输入面板上的地址与配对码。

安全
----
- API Key 保存在 Windows 凭据管理器，不写入 SQLite 或日志。
- Agent 写入与命令默认需要批准；危险命令会被策略拒绝。
- MCP 工具默认逐次审批；自动授权只对完全信任的服务器启用。
- Skill 与 MCP 配置保存在本机应用数据目录，请勿导入不可信插件。
- 仅访问你明确添加的项目目录。
- 远程访问默认关闭；开启后只监听局域网，必须先看到电脑屏幕上的 6 位配对码
  才能换取令牌。不内置公网穿透；如需外网请自行加 VPN 或反向代理，
  并清楚这意味着把整台工作台暴露出去。
- 本项目构建未进行代码签名；Windows SmartScreen / Android 可能显示提示。

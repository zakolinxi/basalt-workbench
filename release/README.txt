BASALT 0.3.1 — Windows x64
==========================

Basalt（玄武）是一个本地优先的 AI 工程工作台（Tauri 2 + React + Rust）。
它把多模型对话、审批门控的编程 Agent、真实终端、变更审查、图像生成与
手机接管放进同一个桌面界面。项目、会话、变更快照和 API Key 都留在本机。

本次更新
--------
- 输入框底部新增余额 chip，显示当前供应商 API Key 的账户余额。
- 点击查看总余额、赠送余额、充值余额与账户可用状态，可手动刷新。
- 每轮对话结束后自动刷新；切换供应商时重新查询。
- 余额查询在 Rust 后端完成，Key 从 Windows 凭据管理器读取，
  不会进入前端、URL 或普通日志。
- 支持 DeepSeek 官方与 Moonshot 官方余额接口；没有公开余额接口的
  兼容网关会自动隐藏该入口。
- 其余：版本号、打包信息与发布说明更新。

运行要求
--------
- Windows 10/11 x64
- Microsoft Edge WebView2 Runtime（Windows 10/11 通常已预装）
- 可选：Git（用于分支、提交、还原、Git 状态与 HEAD Diff）
- 可选：Windows PowerShell（Agent 命令与默认终端）
- 可选：Node.js / uvx（运行外部 MCP stdio 服务器）
- 手机端：Android 或任意现代浏览器；手机与电脑需在同一局域网

两种使用方式
------------
1. 安装版：运行 Basalt_0.3.1_x64-setup.exe，按向导安装。
2. 便携版：直接运行 Basalt.exe。便携版仍使用 %APPDATA%\com.basalt.workbench
   保存数据库、附件、Skills、MCP 配置与设置。

首次使用
--------
- 打开「供应商」，从模板创建供应商并填入 API Key。
- 在「设置 → 模型路由」分别配置 Agent 执行、规划与代码审查模型。
- 在「扩展」导入 Skill 文件夹，或添加 MCP 服务器后刷新工具。
- 添加本地项目目录后，输入框默认处于 Agent 模式。
- 输入框底部可看到当前供应商余额（若该供应商支持余额接口）。
- 输入框「思考」可选 off / minimal / low / medium / high / xhigh / max / ultra。
- 使用 /img 提示词调用独立图像供应商。
- 手机接管：设置 → 手机连接 → 打开开关 → 手机扫码，
  或先安装 Basalt-Remote-0.3.1.apk，再手动输入面板上的地址与配对码。

安全
----
- API Key 保存在 Windows 凭据管理器，不写入 SQLite 或日志。
- Agent 写入与命令默认需要批准；危险命令会被策略拒绝。
- MCP 工具默认逐次审批；自动授权只对完全信任的服务器启用。
- Skill 与 MCP 配置保存在本机应用数据目录，请勿导入不可信插件。
- 仅访问你明确添加的项目目录。
- 远程访问默认关闭；开启后只监听局域网，必须先看到电脑屏幕上的 6 位配对码
  才能换取令牌。不内置公网穿透；如需外网请自行加 VPN 或反向代理，
  并清楚这意味着把整台工作台暴露出去。
- 手机 APK 已用固定 release 证书签名（CN=Basalt，RSA 2048，有效期 10000 天），
  后续版本可覆盖安装。若你之前装过调试签名的版本，需要先卸载再装。
- Windows 安装包未做代码签名；SmartScreen 可能显示提示。

安装手机客户端
--------------
1. 把 Basalt-Remote-0.3.1.apk 传到手机安装（首次需允许「安装未知来源应用」）。
2. 电脑端打开 设置 → 手机连接 → 打开开关，记下面板上的地址与 6 位配对码。
3. 手机打开 Basalt Remote，输入地址与配对码；或用手机浏览器访问
   http://<地址>:7717 后「添加到主屏幕」，效果相同且无需安装。
